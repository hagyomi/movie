# Discover Your Movie Story

**영화 탐색에 타이포그래피와 스크롤 인터랙션을 결합한 프론트엔드 포트폴리오 프로젝트입니다.**

TMDB API를 활용해 장르별 영화 목록과 상세 정보를 제공하고, 영화 이미지와 모션으로 콘텐츠를 탐색하는 경험을 구현했습니다. React 19의 폼 액션과 낙관적 업데이트, Zustand의 상태 관리, GSAP의 스크롤 애니메이션을 함께 적용했습니다.

## 기획 의도

영화 정보를 나열하는 화면에서 한 단계 더 나아가, 영화의 분위기를 시각적으로 전달하는 탐색 경험을 목표로 했습니다. 검정 배경과 큰 타이포그래피, 포스터와 배경 이미지를 중심으로 화면을 구성하고, 스크롤에 따라 콘텐츠가 전환되도록 설계했습니다.

홈 화면은 **인트로 → 장르별 영화 → 타이포그래피 모션 → 느와르 비주얼 → 영화 소개 → 갤러리와 포트폴리오 푸터** 순서로 이어집니다. 영화 카드에서 상세 페이지로 이동해 작품 정보와 예고편을 확인할 수 있습니다.

| 기능             | 구현 내용                                                                             |
| ---------------- | ------------------------------------------------------------------------------------- |

| 스크롤 인터랙션  | 인트로의 단어 전환, 섹션 고정, 가로 이동 등 스크롤 진행에 연동되는 모션을 제공합니다. |
| 영화 목록 패널   | 인기 영화 3페이지의 데이터를 병렬로 조회하고 하나의 목록으로 보여줍니다.              |
| 제목 검색        | 불러온 인기 영화 목록에서 제목을 기준으로 검색합니다.                                 |
| 영화 상세 정보   | 영화 배경 이미지, 작품 정보, 줄거리와 평점을 표시합니다.                              |

| 반응형 화면      | 미디어 쿼리와 Tailwind 반응형 클래스로 목록과 상세 화면의 배치를 조정합니다.          |
| 모션 감소 설정   | 일부 스크롤 섹션에서 사용자의 `prefers-reduced-motion` 설정을 반영합니다.             |

## 구현 포인트

### 1. UI 상태와 영화 데이터 상태 분리

Zustand 스토어를 UI 슬라이스와 영화 데이터 슬라이스로 나눴습니다. 카테고리 선택과 패널 열림 상태는 `createUiSlice`, 영화 조회와 로딩·오류 상태는 `createMovieSlice`에서 관리합니다. 컴포넌트는 필요한 상태를 선택해 구독하고, API 요청 로직은 별도 모듈에 둡니다.

장르를 빠르게 변경하면 `AbortController`로 이전 요청을 취소합니다. 이전 카테고리의 응답이 나중에 도착해 현재 목록을 덮어쓰는 상황을 줄이기 위한 처리입니다.

### 2. 검색 입력과 목록 업데이트의 우선순위 조정

영화 목록 검색에는 `useDeferredValue`와 `useTransition`을 사용했습니다. 입력값은 즉시 반영하고, 지연된 검색어로 수행하는 목록 필터링은 낮은 우선순위로 처리하도록 구성했습니다.

검색 대상은 TMDB 전체 영화가 아닌, 인기 영화 API에서 미리 불러온 3페이지의 데이터입니다.

### 3. React 19 기반 리뷰 인터랙션

`useActionState`로 리뷰 추가·삭제 액션을 관리하고, `useOptimistic`으로 처리 완료 전에 화면을 업데이트합니다. 제출 버튼은 `useFormStatus`의 `pending` 상태에 따라 비활성화하고 `POSTING...` 문구를 표시합니다.

리뷰 저장은 약 1초의 지연을 둔 데모 로직입니다. 현재 리뷰는 컴포넌트 메모리에만 유지되며, 새로고침이나 상세 페이지 이탈 후 재진입 시 초기화됩니다.

### 4. 스크롤과 시각적 스토리 연결

GSAP ScrollTrigger의 `pin`과 `scrub`을 활용해 스크롤 진행과 모션을 연결했습니다. 인트로에서는 “Discover Your Movie Story”를 단어별로 보여주고, 느와르 섹션에서는 타이포그래피와 정보를 순차적으로 전환합니다.

애니메이션은 `gsap.context()`로 범위를 지정하고 컴포넌트 해제 시 `revert()`로 정리합니다. 모션 감소 설정이 활성화된 일부 섹션은 애니메이션 대신 정적인 콘텐츠를 표시합니다.

### 5. 상세 정보와 예고편의 병렬 조회

영화 상세 페이지에서는 작품 정보와 영상 정보를 `Promise.all`로 함께 요청합니다. 영상 목록에서 `Trailer` 유형의 YouTube 영상을 선택해 예고편 모달에 연결합니다.


## 로컬 실행

Node.js와 npm이 설치된 환경에서 실행합니다.

```bash
git clone https://github.com/본인주소
cd movie
npm install
```

프로젝트 루트에 `.env.local` 파일을 만들고 TMDB API 키를 설정합니다. `.env.example`에서 필요한 변수 이름을 확인할 수 있습니다.

```dotenv
VITE_TMDB_API_KEY=your_tmdb_api_key
```

```bash
npm run dev
```

터미널에 표시되는 로컬 주소로 접속합니다.

| 명령어            | 용도                        |
| ----------------- | --------------------------- |
| `npm run dev`     | 개발 서버 실행              |
| `npm run build`   | `dist`에 프로덕션 빌드 생성 |
| `npm run preview` | 빌드 결과를 로컬에서 확인   |
| `npm run lint`    | ESLint 검사                 |

## 배포 설정

Vercel에서 다음 설정으로 배포합니다.

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **환경변수:** `VITE_TMDB_API_KEY`

환경변수는 배포할 환경에 맞게 설정하고, 변경 후 다시 배포해야 합니다. `vercel.json`에는 상세 페이지 직접 접속과 새로고침을 위한 SPA rewrite가 설정되어 있습니다.

`.env` 파일은 Git에 포함하지 않습니다. `VITE_` 접두사의 변수는 클라이언트 빌드에 포함되므로, 서버 전용 비밀값은 이 방식으로 관리하지 않습니다.

## 현재 범위와 개선 계획

- 리뷰를 실제 서버와 연결해 영화별로 저장하고 유지하기
- API 실패, 데이터 없음, 이미지·예고편 없음에 대한 안내 강화하기
- 전체 영화 검색 API와 페이지네이션 추가하기
- 설치된 TanStack Query를 실제 데이터 조회에 적용해 캐시와 요청 상태 관리 통합하기
- 코드 분할을 통해 프로덕션 JavaScript 번들 크기 줄이기
- 키보드 탐색, 모달 포커스 관리와 모바일 모션 경험 개선하기

홈 화면의 `Upcoming` 섹션은 현재 선택된 장르의 영화 데이터를 활용한 소개 영역입니다. 별도의 개봉 예정 영화 API를 조회하는 기능은 아직 구현하지 않았습니다.

## 데이터 출처
